# Task 1 — Game of Life：生命游戏

## 任务

实现 `src/game_of_life_lib.cpp` 中的原始接口：

```cpp
void update_step(int width, int height, uint8_t *buffer);
```

`buffer[y * width + x]` 是坐标 `(x,y)` 的细胞，0 表示死亡，任意非零字节表示存活。
函数原地写回恰好一代的结果；所有细胞必须根据更新前的同一代计算，不能让本次已经写入的结果影响后面的细胞。

一个细胞的邻居是周围八个位置，不包括自身：

- 有 3 个活邻居：下一代存活。
- 有 2 个活邻居：下一代保持自身存活／死亡状态。
- 其他情况：下一代死亡。

有限矩形网格之外永远视为死亡，边界不环绕。
输出仍按 0／非零解释，不强制存活字节必须是 1，也不要求保留输入的非零数值。

## 输入约定

- `0 <= width, height <= 1024`。
- 任一维度为 0 时不做任何操作，此时 `buffer` 可以为 `nullptr`。
- 非空网格中 `buffer` 指向至少 `width * height` 个可读写字节。
- 不要求处理负数维度或非空网格的空指针。
- 请尽可能简洁地完成实现，尝试不开辟新内存空间。
- 只修改 `src/game_of_life_lib.cpp`，不需要图形界面、定时器或主循环。
