# Task 3 — CPU Rasterization

在 `src/draw.cpp` 中实现纯 CPU 像素、线段、实心矩形、圆和三角形绘制。所有图元直接覆盖 RGBA；越界像素忽略。只修改该实现文件。

- 线段使用整数 Bresenham 规则，包含两个端点，必须支持所有八个方向和反向端点。
- 矩形包含两端坐标；端点次序任意，超出图像的部分裁掉。
- 圆包含所有满足 `(px-cx)^2+(py-cy)^2 <= r^2` 的整数像素；负半径无操作。
- 三角形包含边界，与顺/逆时针顺序无关。三点共线时绘制三条边的并集。
- 坐标范围为 `[-100000,100000]`，图像宽高为 `0..2048`；计算不得发生有符号整数溢出。

需要 C++17，无窗口或 GPU；测试和可视化可使用 `../external/stb` 中随仓库提供的图片头文件库。

评测使用 `rectangle.data` 以及线段、矩形、圆和三角形参考图，并在测试端读取预解码像素数据进行离线比较。
